# 🌿✨ SVG Floral Garland with CSS Soft Halo 🌸

A lightweight, responsive SVG floral banner with a soft CSS halo glow effect. Designed for WordPress (Gutenberg) and custom web projects.

## 🚀 How to Use

1. Insert the SVG into your HTML or a WordPress *Custom HTML* block.
2. Apply the `.garland-wrapper` CSS class to render the ambient halo glow and maintain tight vertical margins.

## 🛠️ Features

- **Responsive SVG:** Scales smoothly to any screen width.
- **CSS Ambient Glow:** Soft blurred gradient background behind the vector paths.
- **Zero Dependencies:** Pure HTML and CSS.
